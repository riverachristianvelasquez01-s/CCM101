# MICROSOFT AZURE

## Brief Overview
Origin: Announced in October 2008 under the internal codename "Project Red Dog", Microsoft officially launched Windows Azure in February 2010. It was renamed Microsoft Azure in 2014 to highlight its expansion beyond Windows to open-source software like Linux.
Core Mission: Provide a global public cloud platform offering Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS) to build, deploy, and manage applications using Microsoft tools and open-source technologies.

## Global Infrastructure
Azure Regions: Over 60+ geographical regions globally (eg, East US, West Europe, East Asia) containing clusters of physical datacenters connected by a dedicated low-latency network.
Availability Zones (AZs): Physically separate datacenters within an Azure region equipped with independent power, cooling, and networking to ensure fault isolation and high availability.
Geographies & Edge Locations: Geographies maintain data residency boundaries (such as US, Europe, or Asia-Pacific), while globally distributed edge locations accelerate web content delivery via the Azure Content Delivery Network (CDN).

## Cloud Management Console
Definition: Known as the Azure Portal (portal.azure.com), a web-based graphical user interface (GUI) and mobile app for managing all Azure resources from a single console.
Functionality: Enables administrators and developers to build web apps, configure databases, monitor real-time costs, run Cloud Shell command scripts, manage security access, and track system health metrics.

## Four (4) Core Services
1. Azure Virtual Machines (VMs): Scalable compute resources providing Linux or Windows virtual servers on demand. (https://learn.microsoft.com/en-us/azure/virtual-machines/)
2. Azure Blob Storage: Massively scalable object storage designed for unstructured data such as files, documents, images, video streaming, and system backups. (https://learn.microsoft.com/en-us/azure/storage/blobs/storage-blobs-introduction)
3. Azure SQL Database: Managed relational database service (PaaS) based on Microsoft SQL Server with built-in auto-scaling, automated backups, and patching. (https://learn.microsoft.com/en-us/azure/azure-sql/database/sql-database-paas-overview)
4. Microsoft Entra ID (formerly Azure Active Directory): Cloud-based identity and access management (IAM) service used to control user authentication, single sign-on (SSO), and resource permissions. (https://learn.microsoft.com/en-us/entra/fundamentals/whatis)

## Three (3) Advantages
1. Seamless Microsoft Ecosystem Integration: Native compatibility with existing enterprise tools like Windows Server, SQL Server, Active Directory, and Microsoft 365, making cloud adoption friction-free for businesses.
2. Cost Savings via Azure Hybrid Benefit: Allows enterprises to reuse existing Windows Server and SQL Server licenses in the cloud, significantly reducing costs compared to paying standard pay-as-you-go rates.
3. Hybrid Cloud Dominance (Azure Arc): Enables organizations to run and manage applications seamlessly across on-premises corporate datacenters, multi-cloud platforms, and edge environments from a single dashboard.

## Typical Enterprise Use Cases
- Hybrid Cloud Deployments: Connecting on-premises infrastructure with public cloud environments for secure, scalable hybrid operations.
- Enterprise App Modernization: Shifting legacy Windows/SQL enterprise applications to the cloud without rewriting backend code.
- Generative AI & Data Analytics (Azure OpenAI Service): Deploying advanced AI models (such as GPT-4) securely within private enterprise cloud boundaries alongside big data analytics.

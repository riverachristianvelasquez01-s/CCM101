## Comparison Questions (Q&A)

1. Which cloud provider offers the broadest range of services?

   - Amazon Web Services (AWS) — it has the largest service catalog (200+ services) and the broadest ecosystem.

2. Which provider best integrates with Microsoft technologies?

   - Microsoft Azure — native compatibility with Windows Server, SQL Server, Active Directory, and Microsoft 365.

3. Which provider is strongest in Artificial Intelligence and Kubernetes?

   - Google Cloud Platform (GCP) — strong AI/ML tooling (BigQuery, Vertex AI, TPUs) and Kubernetes leadership (Google originated Kubernetes).

4. Which cloud platform would you personally choose and why?

   - Initially you said you preferred Google because of long personal use, but after researching you would choose Amazon Web Services (AWS) for its market maturity, widespread industry adoption, extensive documentation, pay-as-you-go flexibility, and large service catalog.

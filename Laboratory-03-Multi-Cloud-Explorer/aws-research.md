# AWS

## Brief Overview
Origin: Amazon Web Services (AWS) launched in spring 2006 after Amazon experienced firsthand how difficult and expensive it was to build and manage physical IT infrastructure.
Core Mission: Democratize access to technology by providing enterprise-grade computing power, storage, and databases on demand via the internet to anyone from students to Fortune 500 companies.

## Global Infrastructure
AWS Regions: Geographic areas around the world containing clustered data centers (eg, US East, Europe, Asia Pacific).
Availability Zones (AZs): Multiple isolated, fault-tolerant data centers within each region connected by low-latency networking to ensure high availability.
Edge Locations: Network locations globally distributed to cache and deliver content closer to end-users with single-digit millisecond response times.

## Cloud Management Console
Definition: A centralized web-based graphical user interface (GUI) and mobile app used to access, configure, and monitor AWS services.
Functionality: Allows administrators and developers to deploy resources, manage user access permissions, track active spending, and view system health metrics without writing complex code.

## Four (4) Core Services
1. Amazon EC2 (Elastic Compute Cloud): Provides resizable, on-demand virtual servers for running applications.
2. Amazon S3 (Simple Storage Service): Scalable object storage designed for backup, archiving, and hosting media or data lakes.
3. Amazon RDS (Relational Database Service): Fully managed relational databases (MySQL, PostgreSQL, Oracle) that handle backups, patching, and hardware setup.
4. AWS IAM (Identity and Access Management): Security management service that controls who can access specific AWS resources and features.

## Three (3) Advantages
1. Cost Savings (Pay-As-You-Go): Replaces heavy upfront capital expenditure on physical servers with flexible operational spending, charging only for what you use.
2. Scalability & Elasticity: Resources scale up dynamically to handle sudden traffic spikes and automatically scale down during quiet periods to prevent wasted budget.
3. Agility & Speed: Reduces time to deploy new infrastructure from months to minutes, allowing teams to test and bring applications to market faster.

## Typical Enterprise Use Cases
- Cloud Migration & Modernization: Shifting legacy applications out of expensive on-premises data centers into scalable cloud environments.
- Big Data & Generative AI: Processing massive enterprise datasets and deploying machine learning models or generative AI applications at scale.
- Disaster Recovery & Business Continuity: Replicating data across multiple global regions to prevent downtime and recover critical data instantly during an outage.

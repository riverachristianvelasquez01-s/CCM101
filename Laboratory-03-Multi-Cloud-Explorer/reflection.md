# Reflection
Out of the three platforms, Google Cloud Platform still impressed me the most. Before, I only knew Google for everyday consumer services like Google Drive, Gmail, and YouTube etc. After research,it was really cool to learn that GCP actually runs on that exact same global network and offers powerful tools for big data and AI like BigQuery and Vertex AI. Even though AWS, Azure, and GCP use completely different product names, I noticed they are basically doing the same core jobs. They all give you virtual machines, object storage for files, managed databases, and login security, all built across global regions and availability zones so applications don't go down.

I also realized that picking a cloud provider depends entirely on what a business needs rather than just picking whichever platform is most popular hehehe. For example, a small startup might choose AWS to save money and scale quickly, while a university that already uses Windows Server and Microsoft 365 will save a lot of money sticking with Azure. On the other hand, an AI research team will naturally lean toward GCP for its machine learning tools. Acting like a Cloud Solutions Consultant taught me that you can't just give the exact same recommendation to every client. You have to look at their budget, what software they already use, and what they are trying to build.

So overall, this project made my GitHub Cloud Computing Portfolio look much more complete.
